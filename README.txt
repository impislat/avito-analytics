AVITO ANALYTICS

Это готовый многостраничный сайт для ежедневного сбора статистики Avito.

Страницы:
- index.html — главная
- daily.html — обязательная ежедневная статистика
- cities.html — города и объявления
- promo.html — продвижение и реклама
- analytics.html — аналитика
- reports.html — экспорт данных для ИИ
- settings.html — резервная копия / импорт

ВАЖНО:
Данные хранятся локально в браузере. Для постоянного использования лучше разместить папку на GitHub Pages или другом HTTPS-хостинге. Регулярно скачивай JSON-резервную копию.

Логика:
- 0 / 0 / 0 сохраняется как настоящая запись.
- День считается заполненным, только если запись есть по каждому активному городу.
- В отчёт для ИИ попадают и нули, и отсутствующие записи отдельно.
- Продвижение учитывается через тип и сумму.
